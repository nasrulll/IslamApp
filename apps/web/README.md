# Fikihmu Web — bootstrap

Next.js + TypeScript web skeleton sudah memiliki **beranda** dan **halaman deskripsi** Fikih Muqaran, Sanad Kitab dan Tafsir Ayat. UI ini belum menjalankan pencarian, AI, kitab, atau tafsir. Jalankan dari root: `npm install && npm run dev:web` (port 3000). Perintah lint/typecheck/build tersedia. Rencana MVP mencakup RTL Arab, sumber edisi yang benar, Dual Evidence View, dan aksesibilitas. Baca `../../docs/architecture/DEV-SETUP.md`.
